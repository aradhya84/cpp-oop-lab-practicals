
# Library Management System

## Aim
To develop a console-based Library Management System using C++.

## Features
1. Add new books.
2. Display all books.
3. Search books using Book ID.
4. Issue books.
5. Return books.
6. Save and load book records using CSV files.

## Concepts Used
- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- STL Vector
- Exception Handling
- File Handling

## Files
- main.cpp – Main C++ source code.
- books.csv – Stores book records.

## Compilation
g++ -std=c++17 main.cpp -o library

## Execution
./library
