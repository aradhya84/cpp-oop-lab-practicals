# C++ Fundamentals

## Aim
To demonstrate basic C++ concepts such as data types, variables, constants, operators, and input/output.

## Program Features
- Demonstrates variables and constants.
- Uses arithmetic, relational, and logical operators.
- Accepts user input using `cin`.
- Displays results using `cout`.

## How to Run
1. Open `main.cpp` in a C++ compiler.
2. Compile and run the program.
3. Enter your age and the radius of a circle.
4. View the calculated area and other results.

## Language
C++
